### Theme Selector

![Theme Selector](../../.github/screenshots/theme-selector.svg)

**Access:** Press `T` or click the palette icon

The theme selector includes:
- **Light/Dark toggle** at the top
- **6 theme options** with visual previews
- **Real-time preview** of each theme
- **Persistent selection** saved to localStorage

Each theme features:
- Unique color palette
- Custom typography pairing
- Optimized for readability
- Both light and dark variants

---

### File Selector

![File Selector](../../.github/screenshots/file-selector.svg)

**Access:** Press `O` or click the folder icon

#### Local Files Tab
- Browse your filesystem
- Navigate folders with expand/collapse
- Filter to show only `.md` and `.markdown` files
- Visual folder and file icons
- Select to load instantly

#### Git URL Tab
- Load from GitHub or GitLab
- Support for public repositories
- Direct URL input
- Automatic branch detection
- No download required

**Supported URL formats:**
```
https://github.com/owner/repo/blob/main/slides.md
https://gitlab.com/owner/repo/-/blob/main/slides.md
```

### Keyboard Shortcuts Dialog

![Keyboard Shortcuts](../../.github/screenshots/keyboard-shortcuts.svg)

**Access:** Press `?`

Quick reference for all keyboard shortcuts:

#### Navigation
- `→` `←` `↑` `↓` - Navigate between slides
- `Space` - Next slide

#### Features
- `S` - Show slides list with search
- `T` - Toggle theme selector
- `O` - Open file selector
- `D` - Display current file name
- `F` - Enter fullscreen mode
- `?` - Show this help dialog

#### System
- `Esc` - Exit fullscreen or close dialogs

## 📋 Additional Features

### Slides List Overlay

**Access:** Press `S`

Features:
- See all slides at once
- Live search/filter as you type
- Jump to any slide instantly
- Current slide highlighted
- Keyboard navigation (↑↓ arrows)
- Slide numbers and previews

### Presentation Timer

Located in the top-left corner:
- **Auto-start** when presentation loads
- **Pause/Resume** button
- **Reset** button
- **Format:** MM:SS (or HH:MM:SS for long presentations)

Perfect for:
- Timed presentations
- Practice runs
- Keeping to schedule

### PDF Export

**Access:** Click download icon (top-right)

Features:
- One-click export
- Preserves theme colors
- Maintains formatting
- Includes all slides
- Automatic download

### Progress Indicator

Located in the top-right corner:
- Shows current slide number
- Shows total slide count
- Format: "X / Y"
- Always visible during presentation

## 🎯 Tips for Great Presentations

### Content Tips

1. **One idea per slide** - Keep it focused and clear
2. **Use bullet points** - Break down complex ideas
3. **Add code blocks** - For technical content
4. **Include images** - Visual aids enhance understanding
5. **Short paragraphs** - Easy to read at a glance

### Design Tips

1. **Choose appropriate theme** - Match your topic
2. **Test readability** - Ensure text is visible from distance
3. **Use headings** - Create clear hierarchy
4. **Consistent formatting** - Maintain style throughout
5. **Leave white space** - Don't overcrowd slides

### Presentation Tips

1. **Practice shortcuts** - Navigate smoothly
2. **Test beforehand** - Load and verify slides work
3. **Use timer** - Stay on schedule
4. **Prepare backup** - Export PDF as fallback
5. **Fullscreen mode** - Eliminate distractions
