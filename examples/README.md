## How to Use These Examples

### Loading from the Application

1. **Press `O`** to open the file browser
2. Navigate to the `examples/` folder
3. Select any `.md` file to load it
4. Use arrow keys or click to open the presentation

### Loading from Git URL

Each example can also be loaded from a Git repository if you've published them:

```
https://raw.githubusercontent.com/your-username/your-repo/main/examples/getting-started.md
```

### Customizing for Your Needs

Feel free to:
- Copy and modify these examples
- Use them as templates for your own presentations
- Mix and match slides from different examples
- Adapt the themes and styles

## Creating Your Own Presentations

### Basic Structure

```markdown
# First Slide Title

Content goes here

---

# Second Slide

More content

---

# And so on...
```

### Tips for Great Presentations

1. **One idea per slide** - Keep it focused and clear
2. **Use visual hierarchy** - Headers, subheaders, bullets
3. **Include code examples** - For technical content
4. **Add emoji** - Make it engaging 🎉
5. **Balance text and whitespace** - Don't overcrowd
6. **Tell a story** - Have a beginning, middle, and end

## Keyboard Shortcuts Quick Reference

| Key | Action |
|-----|--------|
| `→` or `Space` | Next slide |

## Troubleshooting

### Slides not rendering correctly?
- Ensure you have blank lines before and after `---`
- Check markdown syntax
- Try reloading the file with `O`

### Theme not looking right?
- Press `T` to try different themes
- Some themes work better for certain content
- Toggle between light and dark modes

### Can't find a file?
- Press `O` to open the browser
- Navigate using arrow keys
- Directories show `📁`, files show `📄`
