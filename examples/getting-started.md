# Getting Started with Markdown Slides 🚀

Welcome to your markdown presentation journey!

This tutorial will show you how to create stunning slide decks using just markdown.

---

## What is Markdown Slides?

A powerful presentation tool that transforms markdown into beautiful slide decks.

**Key Features:**
- 📝 Write presentations in markdown
- ⌨️ Navigate with keyboard shortcuts
- 🎨 Multiple themes with dark/light modes
- 📂 Load from local files or Git URLs
- ⏱️ Built-in presentation timer
- 📄 Export to PDF

---

## Creating Your First Slide

Simply write markdown and separate slides with `---`

```markdown
# My First Slide

Hello World!

---

# My Second Slide

More content here
```

That's it! Each section becomes a new slide.

---

## Essential Keyboard Shortcuts

| Key | Action |
|-----|--------|
| `→` or `Space` | Next slide |
| `←` | Previous slide |
| `Home` | First slide |
| `End` | Last slide |

*Tip: These work with touch gestures too!*

---

## More Shortcuts to Know

| Key | Action |
|-----|--------|
| `T` | Toggle theme selector |
| `O` | Open file/directory browser |
| `S` | Search and jump to slides |
| `D` | Display current file name |
| `?` | Show all shortcuts |
| `F` | Toggle fullscreen |

---

## Loading Presentations

### Local Files (Press `O`)
1. Press `O` to open file browser
2. Navigate directories
3. Select your `.md` file
4. Presentation loads instantly

### Git URLs
1. Click the URL button in the toolbar
2. Paste GitHub/GitLab raw markdown URL
3. Hit enter to load

---

## Working with Themes

Press `T` to open the theme selector

**Available Themes:**
- 🌅 Solarized (light & dark)
- 🧛 Dracula (light & dark)  
- 💻 Code (light & dark)

Each theme has carefully selected typography and color palettes!

---

## Using the Slide Navigator

Press `S` to open the slide search & navigator

**Features:**
- 🔍 Real-time search through all slides
- ⌨️ Arrow keys to navigate results
- 👆 Click to jump to any slide
- 🎯 See slide preview text

*Pro tip: Keyboard shortcuts are disabled while search is active*

---

## Presentation Timer ⏱️

The timer appears when you start presenting:

- **Elapsed Time**: Shows how long you've been presenting
- **Current Slide**: Displays slide number
- **Progress Bar**: Visual indication of progress

Perfect for practicing your timing!

---

## Exporting to PDF 📄

Want to share your presentation?

1. Click the "Export PDF" button in the toolbar
2. Wait for the export to complete
3. PDF downloads automatically
4. Each slide becomes a page

Share your presentations anywhere!

## Best Practices 💡

1. **One main idea per slide** - Keep it focused
2. **Use headings** - They become slide titles
3. **Embrace whitespace** - Don't overcrowd
4. **Visual hierarchy** - Use different heading levels
5. **Code examples** - Show, don't just tell

## Advanced: Git URLs

Load presentations directly from repositories:

**GitHub URL Format:**
```
https://raw.githubusercontent.com/
user/repo/branch/path/to/file.md
```

**GitLab URL Format:**
```
https://gitlab.com/user/repo/-/raw/
branch/path/to/file.md
```

Perfect for sharing and collaboration!

## Troubleshooting Common Issues

### Slides not separating?
- Make sure you use exactly `---` on its own line
- Add blank lines before and after `---`

### Theme not changing?
- Press `T` to open theme selector
- Try switching between light/dark mode

### Shortcuts not working?
- Close any open dialogs or search
- Make sure you're not in an input field
